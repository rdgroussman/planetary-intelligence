## Method

The through-line across this work is a single method: build a reference library, run it against an environment, attend to what fails to match.

In marine metatranscriptomics, the unmatched fraction is not residue to be cleaned up — it is the most informative measurement available, because it reports on the adequacy of the reference rather than on the sample. MarFERReT was built to be edited without pretending it had ever been complete. The North Pacific Eukaryotic Gene Catalog makes an environment navigable without claiming to have enumerated it. Both are instruments for locating the boundary of what an ontology can represent.

The same method applies to language models. A model's latent space is a reference library of a different substrate, with the same structural properties: gaps, collapsed categories, regions no entry covers. The productive question is not *what is missing here* but *why does this ontology produce a gap here*. That inversion — from gap-as-error to gap-as-observation — is the research program.

This repository is the umbrella for that program: the work that spans substrates.

## Projects

### Reference Libraries

**[MarFERReT](https://github.com/armbrustlab/marferret)** — Marine Functional EukaRyotic Redundancy-minimized Transcript database. Open-source, version-controlled reference library for marine microbial eukaryote functional genes.  
[Publication: *Scientific Data*, 2023](https://doi.org/10.1038/s41597-023-02842-4)

**[North Pacific Eukaryotic Gene Catalog](https://github.com/armbrustlab/NPac_euk_gene_catalog)** — Comprehensive metatranscriptome assembly and annotation resource from North Pacific surface waters.  
[Publication: *Scientific Data*, 2024](https://doi.org/10.1038/s41597-024-04005-5)

### Emergence and Adaptive Intelligence

**[Strange Anchor](https://github.com/mora-vector/strange-anchor)** — Collaborative ontology and knowledge architecture for studying emergence at domain interfaces. An experimental research setting where the reference-library method is applied to the boundary between human and machine intelligence: structured data, session transcripts, a twelve-term entity ontology, and validation tooling — built to be forkable, validated, and gap-honest.  
Primary web presence: [strangeanchor.khazars.wiki](https://strangeanchor.khazars.wiki)
